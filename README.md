# 📊 Supplement Sales Data Analysis

## 🚀 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** and **Data Visualization** on a Supplement Sales dataset obtained from Kaggle. The analysis was conducted using **Python** in **Visual Studio Code (VS Code)** to uncover business insights, sales trends, customer behavior patterns, and product performance.

The project leverages:

- **Pandas** for data cleaning and manipulation
- **Matplotlib** for static visualizations
- **Seaborn** for statistical graphics
- **Plotly Express** for interactive visualizations

---

## 📂 Dataset Information

**Dataset Name:** Supplement Sales Data

**Source:** Kaggle

🔗 **Dataset Link:**
https://www.kaggle.com/datasets/zahidmughal2343/supplement-sales-data
